# 规格：PikaDesk 本地中国象棋工作台

状态：`Approved for implementation`
日期：2026-08-26

## 1. 目标

为 Windows 10/11 x64 用户构建一款完全免费、本地优先、无需鲨鱼 VIP 许可证的中国象棋分析与授权自动走棋工具。它以皮卡鱼等 UCI/UCCI 引擎为棋力核心，以 TCHESS 的公开源码为工程基座，最终覆盖鲨鱼 VIP 官方公开的主要任务能力。

目标用户首先是本人娱乐、复盘、引擎研究和本地自动对弈；不是公共平台排位代打工具。

“达到鲨鱼 VIP 效果”的定义：`docs/shark-vip-parity-matrix.md` 中所有 P0/P1 项目均通过自动测试或可复现手工验收，且稳定性门槛满足第 10 节。它不表示复制鲨鱼私有代码、私有模型、品牌、素材或界面。

## 2. 已公开假设

1. 首发平台是 Windows 10/11 x64，125%/150%/200% DPI 必须覆盖。
2. 项目暂名 PikaDesk，可在实现前改名。
3. 个人非商用优先，但源码和衍生分发仍严格遵守 GPLv3 及各模型/权重许可证。
4. TCHESS 是主线代码库；其他开源项目只提供可追溯的设计参考。
5. 皮卡鱼作为独立进程接入，不把引擎或权重偷偷打包成来源不明的附件。
6. 自动走棋只对用户主动选择并授权的本地/离线/自有窗口启用，默认关闭。
7. 不建设公共平台专用反检测、隐蔽挂机、排位托管或封禁规避。

## 3. 用户能力

### 3.1 P0：首个可用版本

- 添加、启动、停止皮卡鱼，显示实时深度、分数、节点、速度、主变化。
- 手动摆局、FEN 导入导出、走棋、悔棋、保存/打开棋谱。
- 为一个本地测试棋盘创建连接配置：选择窗口、校准棋盘、识别局面。
- 识别后进行合法性检查；只有高置信度且局面连续时才允许请求引擎。
- 自动落子后视觉确认；不一致、超时、窗口切换或用户移动鼠标时立即暂停。
- 全局紧急停止快捷键和始终可见的自动化状态提示。

### 3.2 P1：VIP 功能对等

- 最多五个引擎同时分析，可单独设置线程、哈希、MultiPV、限时和优先级。
- 保存并复用连接配置：窗口匹配、棋盘区域、坐标、方向、主题、识别模型、点击方式。
- 按比分、开中残局、剩余时间、步数和局面复杂度切换时间方案。
- 安全的智能脚本规则，不允许执行任意 PowerShell、CMD、JavaScript 或原生命令。
- 分支棋谱树、注释、评估曲线、关键失误标记、对比多个引擎。
- XQF/CBR/TXQ/PGN 导入导出；XQB 开局库查询与批量生成；PF/OBK 在公开证据允许范围内只读查询。
- 引擎循环赛/淘汰赛、时间控制、断点恢复、结果与棋谱导出。
- 中文语音提示、SVG/PNG 棋子和可访问主题。

### 3.3 P2：增强项

- 本地棋谱数据库搜索、相似局面和批量分析报告。
- 可选的实体棋盘/摄像头识别。
- Linux/macOS 验证，但不得降低 Windows 首版质量。

## 4. 非目标

- 不破解或修改鲨鱼免费版成为付费版。
- 不反编译、注入、读取鲨鱼进程内存或复制其资源。
- 不保证适配所有第三方平台；采用通用校准和用户授权配置。
- 不提供真人对战公共平台的隐蔽自动化配置或规避检测。
- 不承诺棋力超过具体商业配置；棋力取决于引擎、权重、硬件和时间控制。

## 5. 技术栈

- Java：21（从现有 `pom.xml` 检测）。
- UI：JavaFX 23.0.1。
- 构建：Maven Wrapper，固定 Maven 版本；首个工程任务建立。
- 识别：ONNX Runtime 1.19.2；模型以单独许可清单管理。
- 系统集成：JNA 5.15.0；全局快捷键使用 jnativehook 2.1.0，后续评估维护状态。
- 数据：SQLite JDBC 3.45.2.0；配置和棋谱数据库采用版本化迁移。
- 测试：JUnit 5、AssertJ；系统边界用可替换接口和 Windows 专用集成测试。

版本升级必须先查官方文档和兼容说明，不在同一功能提交中顺手升级。

## 6. 目标命令

任务 1 建立 Maven Wrapper 后，所有开发者只使用下列命令：

```powershell
# 全量测试
.\mvnw.cmd --batch-mode test

# 质量门与打包
.\mvnw.cmd --batch-mode verify

# 本地启动
.\mvnw.cmd javafx:run

# 生成 Windows 本地开发运行时镜像
.\scripts\package-windows.ps1
```

CI 使用相同 Wrapper 和锁定 JDK，不依赖机器全局 Maven。

## 8. 代码风格

- Java 21，四空格缩进，UTF-8；类型 `UpperCamelCase`，成员和方法 `lowerCamelCase`，常量 `UPPER_SNAKE_CASE`。
- 优先不可变值对象、显式状态和窄接口；不要让 JavaFX 控制器直接调用 Win32 或 ONNX。
- 所有外部边界返回结构化结果，不用 `null` 表示错误。

```java
public record RecognitionResult(BoardPosition position, double confidence) {
    public RecognitionResult {
        Objects.requireNonNull(position, "position");
        if (confidence < 0.0 || confidence > 1.0) {
            throw new IllegalArgumentException("confidence must be between 0 and 1");
        }
    }
}
```

## 9. 测试策略

- 单元测试约 80%：规则、FEN、时间策略、脚本规则、坐标映射、状态机。
- 集成测试约 15%：真实皮卡鱼进程、ONNX 推理、SQLite、Windows 截图/鼠标适配器。
- 端到端约 5%：自带的本地测试棋盘，不依赖任何公共游戏平台。
- 每个行为变更执行 Red → Green → Refactor；修复必须先写能复现的失败测试。
- 识别数据集按主题、DPI、方向分层；报告棋盘定位率、逐子准确率、完整局面准确率。
- 自动落子可靠性用连续模拟对局衡量，不以一次成功截图作为完成证明。

## 10. 成功标准

### 功能

- `docs/shark-vip-parity-matrix.md` 的 P0/P1 项全部为 `通过`，每项带测试或手工证据。
- 同一工作区可配置并并行显示 5 个 UCI/UCCI 引擎。
- 分支棋谱、时间方案、受限脚本、开局库批处理、引擎赛、语音和主题均能由普通用户完成。

### 识别与自动化

- 受支持测试集上，棋盘定位成功率 ≥ 99.5%，完整局面识别准确率 ≥ 99.0%。
- 本地测试棋盘连续 1,000 个半回合自动落子：零错误落子；识别不确定时允许安全暂停，不允许猜测执行。
- 窗口失焦、尺寸变化、DPI 改变、动画未完成、局面跳变、非法局面、引擎超时均能停止并解释原因。
- 从用户触发紧急停止到不再产生鼠标事件 ≤ 100ms。

### 工程质量

- 新机器按文档可复现构建；测试、验证和打包命令全部成功。
- 不含已知可达的高危/严重依赖问题；没有秘密、来源不明二进制或许可证缺口。
- 崩溃后不自动恢复点击；恢复必须人工确认当前棋盘和目标窗口。

## 11. 边界

### 始终执行

- 校验所有 FEN、棋谱、图片、配置、模型清单和外部引擎输出。
- 外部进程使用参数列表，不拼接 shell 命令；配置写入采用原子替换。
- 自动化目标必须可见、已授权、在允许列表中，且窗口身份在每步前复核。
- 测试和构建通过后才提交；提交前检查秘密和新增二进制来源。

### 先询问用户

- 新增依赖或替换识别模型。
- 下载并运行鲨鱼免费版进行黑盒 UX 对照。
- 扩展到新的第三方平台或改变自动化安全限制。
- 分发皮卡鱼二进制/NNUE 权重，或发布安装包到外部网站。

### 绝不执行

- 修改鲨鱼授权、补丁、破解、反编译、注入、内存读取或资源提取。
- 任意脚本执行、隐藏窗口控制、反检测、验证码绕过或公共排位托管。
- 置信度不足、局面非法、目标身份不符时继续点击。
- 提交密钥、隐私截图、用户账号信息或来源不明模型。

## 12. Definition of Done

每个任务只有同时满足以下条件才算完成：验收条件全部满足；新增行为有测试；全量测试与构建通过；没有跳过测试；安全边界复核；许可证/来源有记录；用户可见变化有文档；Git 提交单一、可回滚；工作区无意外修改。
