# ADR-0002：远端公开操作由项目所有者逐次授权

## 状态

已接受

## 日期

2026-08-29

## 背景

PikaDesk 的 GitHub 仓库是公开源码与审计材料的对外窗口。推送提交、修改仓库介绍、创建 Release、标签、Pull Request 或 Issue 都会改变公开状态，可能影响使用者、许可证审计和项目叙事。

项目所有者要求：后续实现、文档和本地构建可以继续完成并保留在本机，但只有在本次对话中获得明确授权时，才能执行 GitHub 远端变更。

## 决策

默认只进行本地编辑、测试、打包和本地 Git 提交。除非项目所有者明确说明本次允许的远端范围，否则智能体不得执行：

- `git push`、强制推送、远端分支/标签操作；
- GitHub Release、Pull Request、Issue、仓库设置或 About 信息变更；
- 任何通过 `gh`、GitHub API 或网页完成的公开状态写入。

一次明确授权只覆盖用户点名的仓库、分支或操作，不自动延伸到后续改动。准备好但未上传的工作应报告本地提交、测试结果、文件范围和待推送差异，等待新的授权。

## 后果

- 本地开发可以持续、可验证、可回退，不会因为等待发布许可而停止。
- `main` 与 `origin/main` 可能暂时不同步；这是有意的所有者控制，而不是失败。
- 发布前需要再次检查来源、许可证、测试与具体推送范围。
