## 对等验收原则

1. 每一行都需要证据编号，证据可为单元测试、集成测试、E2E 记录或可复现手工步骤。
2. “已有”不等于“通过”；TCHESS 现有功能必须先跑基线测试。
3. 任何会产生外部鼠标事件的能力都必须同时满足威胁模型中的授权、确认和熔断要求。
4. 鲨鱼后续新增公开功能时，只进入待评估清单，不自动扩张当前版本范围。
